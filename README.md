
An adaptation research of DTrOCR: Decoder-only Transformer for Optical Character Recognition for MDPI Engineering Proceedings-ETLTC 2026—LLM for Japanese Text OCR: Automating Kuzushiji Recognition Using Decoder-only OCR Architecture.

This repository uses Masato Fujitake's DTrOCR research as a basis for training a model used for Japanese text OCR.
## Acknowledgments
The project is based on Arvind Rajan's implementation of original research (https://github.com/arvindrajan92/DTrOCR). We utilize ViT by Hugging Face and a language model Japanese GPT-2-medium by Rinna Co (https://huggingface.co/rinna/japanese-gpt2-small) through Hugging Face's Transformers library. For synthetized data generation we use Text Renderer (https://github.com/oh-my-ocr/text_renderer).
